Оформить тариф можно в разделе [«Подписка»](https://web.vispy.net/subscriptions) личного кабинета. При оплате сразу на 2, 3 или 6 месяцев действует скидка −5%, −10% и −20% соответственно (кроме тарифа «Суточный» — он продаётся только на сутки).

<Frame>
  ![Страница выбора тарифа](/images/account/tariffs.png)
</Frame>

|  | Суточный | Базовый | Стандартный | Премиум |
| --- | --- | --- | --- | --- |
| Цена | 15 ₽/сут | от 100 ₽/мес | от 200 ₽/мес | от 300 ₽/мес |
| Трафик | 50 ГБ/день | 300 ГБ/мес | 1000 ГБ/мес | 1500 ГБ/мес |
| Устройств в тарифе | 1 | 1 | 3 | 5 |
| Макс. устройств (с докупкой) | 10 | 3 | 5 | 20 |
| Доп. устройство | 75 ₽/мес | 50 ₽/мес | 50 ₽/мес | 50 ₽/мес |
| Докупка трафика | — | ✓ | ✓ | ✓ |
| Поддержка 24/7 | ✓ | ✓ | ✓ | ✓ |

<Info>
  «Стандартный» — оптимальный выбор по соотношению цены и лимитов, «Премиум» подойдёт для семьи или команды с несколькими устройствами.
</Info>

<Tip>
  Если у вас есть статус лояльности (см. [«Статусы и скидки»](/account/loyalty-statuses)), персональная скидка применится к цене автоматически — при оформлении подписки вы увидите блок «Ваша группа» с уже посчитанной ценой.
</Tip>

## Локации по тарифам

Набор доступных серверов различается по тарифу — «Суточный» и «Премиум» дают доступ ко всем локациям, «Базовый» и «Стандартный» — только к части из них. У всех, кроме «Базового» тарифа есть специальный сервер **«LTE Белые списки»** (расход трафика на нём считается ×5). Актуальный список локаций для активной подписки — на странице [«Подписка»](/account/subscription-management).

| --- | --- | --- | --- | --- |
| 🇫🇷 Франция | ✓ | — | — | ✓ |
| 🇪🇪 Эстония | ✓ | — | — | ✓ |
| 🇨🇿 Чехия | ✓ | — | ✓ | ✓ |
| 🇳🇱 Нидерланды | ✓ | ✓ | ✓ | ✓ |
| 🇸🇪 Швеция | ✓ | ✓ | ✓ | ✓ |
| 🇵🇱 Польша | ✓ | ✓ | ✓ | ✓ |
| 🇺🇸 США | ✓ | ✓ | ✓ | ✓ |
